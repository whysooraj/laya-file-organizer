Quickstart

Organize in two minutes

Works on macOS, Linux, and Windows with Python 3.9+.

01

Clone the organizer script

Clone the lightweight repository to your home directory.

git clone https://github.com/sooraj-makala/laya-file-organizer.git && cd laya-file-organizer
02

Preview changes with --dry-run

Inspect exactly where files will move without altering anything on disk.

python laya_organizer.py ~/Downloads --dry-run
03

Execute organization

Run without flags to organize your directory cleanly.

python laya_organizer.py ~/Downloads
