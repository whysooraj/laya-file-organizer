// SAFETY, INTEGRITY & DUPLICATE COLLISION GUARDS

• 1KB Text Ceiling: Only the first 1,000 characters of UTF-8 text are inspected. This guarantees O(1) constant-time extraction without reading gigabytes of log files into memory.

• Non-Destructive Collision Protection: If a destination folder already contains a file with the identical name, Laya automatically increments a _dup1, _dup2 suffix rather than overwriting existing records.

• Safe Quarantine: Any file scoring below the confidence threshold (< 0.50 by default) is moved to Uncertain/ for human inspection rather than misfiled.
