Getting Started

Up and running in three steps

Works on macOS, Linux, and Windows with standard Python 3.9+.

1

Clone the repository

Clone the lightweight repository to your local computer.

git clone https://github.com/whysooraj/laya-file-organizer.git
2

Run a dry-run check

Inspect proposed file moves safely without altering your disk.

python laya_organizer.py ~/Downloads --dry-run
3

Execute organization

Apply the clean organization passes with one command.

python laya_organizer.py ~/Downloads

Clean downloads. Zero effort.
