Local-First Architecture

Zero cloud uploads. 100% private.

Your Downloads folder contains invoices, contracts, personal photos, and sensitive data. Laya runs entirely on your CPU with no remote API dependencies.

Cloud LLM Organizers
  • Sends sensitive filenames and snippets to remote servers
  • Requires third-party API keys (OpenAI / Anthropic bills)
  • High round-trip network latency (800ms - 2500ms per file)
  • Stops working completely when airplane mode is on
Laya Local Engine
  • 100% on-device forward pass. 0 outbound network bytes
  • No accounts, zero API keys, and zero subscription costs
  • Sub-35ms local execution speed on standard CPU
  • Works seamlessly offline, during flights, or air-gapped

Flag / Argument Type Description Example
--dry-run Boolean Flag Simulate organization paths without moving or creating files on disk python3 laya_organizer.py ~/Downloads --dry-run
-o, --output Directory Path Target directory for organized folders. Preserves original directory if specified python3 laya_organizer.py ~/Downloads -o ~/Organized
--confidence Float (0.0 - 1.0) Minimum certainty threshold (default 0.50). Predictions below this route to Uncertain/ python3 laya_organizer.py ~/Downloads --confidence 0.75
--check Verification Flag Runs the embedded test suite and self-check diagnostics on the decision router python3 laya_organizer.py --check
Common Questions

Frequently Asked Questions

Does Laya ever delete my files?

Never. Laya only performs safe directory moves. Temporary scrap and cache files are routed to Junk_Candidates/ so you can review them before deleting anything manually.

What if a file with the same name exists?

Laya includes collision detection. If report.pdf already exists in the destination folder, Laya renames the incoming file to report_dup_1.pdf to prevent data loss.

Does Laya need an internet connection?

No. Laya is powered by a lightweight local decision engine that executes directly on your CPU. It transmits zero bytes to any server and works seamlessly in airplane mode.

Can I organize without touching my original files?

Yes. Use the -o / --output <path> argument to route organized categories to a separate directory, or use --dry-run to preview everything in your terminal first.
